Approvals

The agent stops before these tools and waits for someone to approve or reject the call.

The tools' function names, separated by commas. Leave empty to turn approvals off.

A run nobody is chatting in (a trigger, the API, A2A, MCP, Slack, an eval) always waits for an administrator.

The message names the agent, the tool and the arguments' names, never their values, with a link to the request. Without one here, agents of the Default workspace use the server's default, if one is set.

Only for requests an administrator decides. A request the person chatting decides waits for them.
